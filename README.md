# NULL — THE LIVING TOUCH

Godot 4.7.2 mobile game project. Android debug APK is built automatically by GitHub Actions on pushes to `main`.

- Project guide: [Arabic README](README_AR.md)
- Build workflow: [Android APK](.github/workflows/android-apk.yml)
- Build results: [GitHub Actions](../../actions)
- Download latest APK: [Releases](../../releases)

The output is a development/debug APK intended for device testing. A Play Store release needs a properly managed release signing key and a separate AAB export.
