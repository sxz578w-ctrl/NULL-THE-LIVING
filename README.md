# AFTERZERO

لعبة أكشن وبقاء واستكشاف ثلاثية الأبعاد بمنظور علوي، مصممة للهاتف أولاً بمحرك Godot 4.7.2 Stable.

## الفكرة الأساسية

العالم يتغير وفق قرارات اللاعب عبر نظام **World Pulse**: تثبيت المنطقة (ANCHOR)، حصادها (HARVEST)، أو تغيير ممراتها (REFRACT). هذه النتائج تربط الاستكشاف والقتال والألغاز والبناء في حلقة واحدة.

## التقنية

- Godot 4.7.2 Stable / GDScript
- Android ARM64، Landscape، Compatibility renderer
- عربي RTL وإنجليزي LTR
- Offline-first؛ لا خادم أو حسابات في النسخة الأولى

## الحالة

AFTERZERO Prototype 0.1 — Vertical Slice قيد البناء. لا يتم إعلان توفر APK قبل نجاح اختبارات المشروع وبناء Android فعلياً.

> ملاحظة المستودع: يستخدم هذا المشروع فرعاً مستقلاً داخل مستودع NULL-THE-LIVING السابق؛ فرع main الأصلي لم يتم تغييره.
